# Арка «Кокошник»

Статическая страница по заданию из `prompt.md`. Откройте `index.html` в браузере — сборка, сервер и установка зависимостей для сайта не нужны.

## Состав

- `index.html` — разделы, команда, логотипы, ссылка на курс.
- `styles.css` — mobile-first оформление, адаптация для планшетов и компьютеров.
- `script.js` — необязательное появление блоков при прокрутке; без JavaScript всё содержимое и ссылки доступны.
- `images/` — исходные материалы; `images/optimized/` — облегчённые версии для сайта.

На телефоне используется квадратный кадр главного изображения, сохраняющий контур арки. Схема открывается в исходном размере по нажатию. Ссылка курса `https://qrco.de/bh1jH8` извлечена из предоставленного QR-кода. Доступность конечной страницы курса не подтверждена; ссылка и QR ведут на один и тот же адрес.

Описательные тексты разделов «О проекте» и «Технология» подготовлены по предоставленным изображениям и теме задания. В ТЗ готовых текстов этих разделов нет; перед публикацией их стоит сверить с авторами проекта.

## Проверка

Браузерная проверка в Chrome: ширины 360, 390, 430, 768, 1024 и 1440 px, основной мобильный viewport 390 × 844. Проверяются горизонтальное переполнение, загрузка изображений, размеры ссылок, смещения макета, навигация, открытие схемы, сканирование отображаемого QR, отключённый JavaScript и уменьшение движения.

Повторный запуск инструментов (Python 3, установленный Chrome):

```powershell
python -m pip install --target .tools pillow zxing-cpp playwright
python scripts/prepare_assets.py
python scripts/check_layout.py
```

Снимки страниц и отчёт сохраняются в `artifacts/`. Зависимости инструментов в `.tools/` не используются сайтом и не нужны для публикации.

Для размещения достаточно `index.html`, `styles.css`, `script.js`, `favicon.svg`, `images/optimized/` и `images/Scheme.png`.
